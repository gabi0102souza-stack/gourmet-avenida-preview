## Tratamento e créditos

Conversão técnica para WebP/AVIF e redimensionamento para 640/1200 px, sem geração, retoque, remoção de marcas ou substituição de comida. As sobreposições e marcas originais permanecem. CSS ajusta enquadramento responsivo no salão. A versão original não é distribuída no artefato público. Todas as fotos são identificadas como arquivo junto à imagem, e a página `fontes.html` apresenta créditos e URLs.

Dimensões originais usadas: buffet 1200×802; saladas 1200×900; salão 1200×540. AVIF desktop total ~248 KB; seleção mobile das três imagens ~78 KB. Somente a foto do hero tem prioridade alta; demais usam `loading=lazy`, `decoding=async`.
